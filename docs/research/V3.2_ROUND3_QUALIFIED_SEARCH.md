## 最低资格标准

QUALIFIED必须同时包含10项产品门槛和独立人民币税后账本。只保存原件、手填PASS或软件测试通过不能批准其他门槛。通过必须绑定产品、期间、资金规模、账户路径和源文件；其他产品或期间不得复用。

| 门槛 | 本轮结果和仍需落实的证据 |
|---|---|
| 产品身份与上市日期 | 8只身份证据通过；实施期间必须晚于上市日。 |
| 普通证券账户二级买入路径 | 已核实ETF二级交易结构；所选期间券商销售适当性、交易权限和规则档案未闭环，不请求私人账户 |
| 期间交易日历、停牌及延期可执行 | 缺期间完整停复牌、有效交易日历和预登记延期规则逐次成交/未成交记录 |
| 人民币价格、净值、分红与拆并份额历史 | 缺完整真实人民币日价格/NAV、分红、份额折算与拆并数据；累计净值不能直接当复权价格 |
| 有效期费用、券商佣金及最低收费 | 产品运作费快照已核实；缺适用券商佣金、最低收费及有效期，真实NAV费用不重复扣 |
| 真实产品与正确基准跟踪误差 | 合同控制目标不是实现值；缺正确基准与真实基金每日净值的同频对齐计算 |
| 成交额、订单规模与买卖价差 | 缺20交易日人民币成交额、委托时盘口价差与深度；做市商名单不能代替实现流动性 |
| 同步参考估值、折溢价与成交限制 | 缺委托时同步价格/参考估值时间戳与历史折溢价；风险公告不是精确溢价率 |
| 投资者、基金内与境外底层税务适用 | 已补开放式基金税主体范围；各产品、二级路径、所得类别、底层税/NAV内税费和期间变更尚未闭环 |
| 历史可知时间、无未来数据 | 2026抓取的摘要不能假装2025交易前已知；缺历史发布/估值/可知时刻档案 |

预登记的研究门槛如下，不是监管规定或流动性安全保证：20日人民币成交额中位数≥1000万元；单笔委托≤此前20日平均成交额1%；相对买卖价差≤0.5%；买卖两端与同步参考估值偏离绝对值≤1%；委托前60秒内的盘口与参考时间戳；可见买卖深度覆盖订单。至少252个历史交易观测；完整日历与规则允许最多延期5个有效交易日。

年度再平衡，在信号后的下一有效交易日14:50尝试成交。停牌、价格限制或上述约束未满足时，延期并记录未成交；不能强行按净值填单。分红留现金至下次再平衡。连续可执行不要求每个交易日都能买到，但必须重建每次计划委托、延期、取消和退出；历史不够表示证据不足。

人民币税后账本还必须独立核验现金/持仓守恒、分红和拆并份额、订单价格/数量/交收、有效期佣金和税务、历史可知信息、完整重放和正确现金流单位化收益。资格筛查器只消费经过审查的独立账本证据，不冒充已经编写并运行的真实产品回测。当前没有这份账本，正式税后CAGR、终值和MDD均为空。

## 税务补证解决了什么

本轮补取财税〔2002〕128号官方原文，范围为证监会批准设立的开放式证券投资基金，分别规定个人申赎差价、基金分配、基金层所得和申赎印花税等事项。它与1998年封闭式基金范围不同。另取上交所2013年ETF投资者教育材料，说明普通证券账户二级路径及当时税费口径。

这两份材料推进了范围核验，却不能只凭旧文和教育材料把8只产品在2025–2026期间所有二级所得、黄金/QDII结构、基金内税和境外底层税全部置零。成文/送出日期和首次可知时间分别记录；未查明的首次发布时间保持空。税务应用门槛继续未通过，缺口明确写入每只产品。

## 下一份闭环证据包

优先处理510300＋511010。这是所需产品和机制较少的股债起点，不是已证明最佳或推荐的配置。一次闭环应提供：

1. 共同期间完整的官方真实人民币日价格/NAV、分红、份额折算/拆并与各自正确基准；含必要预热数据和退出日。
2. 逐日交易日历与停复牌档案、每次计划委托的价差/深度/同步估值/成交额，以及延期和结算规则。
3. 明确适用普通证券路径的公开券商费用表、最低收费、有效日期；明确产品和所得类别的税务应用记录，基金内与投资者层分开。
4. 无未来信息的可知时间档案及独立人民币账户重放；全部门槛过后才开放正式收益。

找到首个合格组合时，记录它首次通过的证据、确认时刻、适用期间和资本范围。若结构最终更简单，那是现实实施结论；目前还没有证据宣布简单组合胜出或把V3.2冻结为可实施版本。
